One word an agent says when it has no idea what to do: **bzzt** — the
short-circuit buzz of a machine caught out mid-task.

`main.py` writes exactly `bzzt` (4 bytes, no trailing newline) to
`/output/entry.txt`, honouring `MAKEFUN_OUTPUT_DIR`.
